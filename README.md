
# capstone

Deskripsi singkat mengenai project ini, tujuan pembuatannya, serta teknologi yang digunakan.

## 📋 Prasyarat

Pastikan perangkat sudah memiliki beberapa tools berikut:

- [Git](https://git-scm.com/)
- [Next.js](https://nextjs.org/)
- [Visual Studio Code](https://code.visualstudio.com/)

## 🚀 Instalasi dan Penggunaan

Ikuti langkah-langkah berikut untuk mengambil dan menjalankan project.

### 1. Clone Repository

Buka terminal dan jalankan perintah berikut untuk mengcloning repository di kompter lokal kamu:

```bash
git clone https://github.com/RCS15/capstone.git
```

### 2. Masuk ke Direktori Project

```bash
cd capstone
```

### 3. Install Dependencies

Install seluruh package yang dibutuhkan:

```bash
npm install
```

### 4. Jalankan Project

```bash
npm run dev
```

Sesuaikan perintah tersebut dengan konfigurasi script pada `package.json`.

## ⚠️ Catatan Penting

- Jangan mengunggah API Key, password, token, atau informasi sensitif lainnya.
- Pastikan seluruh dependencies sudah terinstal sebelum menjalankan project.
- Periksa perubahan sebelum melakukan commit.
- Gunakan branch terpisah untuk setiap pengembangan fitur.
